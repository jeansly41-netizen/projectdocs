Lost in Tra(i)nslation

Op deze website toon ik mijn proces voor het project Lost in Tra(i)nslation. Stap voor stap laat ik zien hoe ik van eerste potloodschetsen naar digitale schermen in Figma ben gegaan.

Elke week beschrijf ik wat ik precies gedaan heb, welke keuzes ik gemaakt heb en hoe mijn ontwerp voor het treininformatiesysteem telkens een beetje beter werd.
